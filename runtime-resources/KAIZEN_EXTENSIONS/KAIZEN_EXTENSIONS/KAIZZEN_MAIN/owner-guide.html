🔑 KAIZEN · Mis contraseñas de Chromium

Tu perfil Chromium puede guardar tus propias cuentas y ofrecer autocompletado al abrir los enlaces de las tarjetas, sin modificar el servidor KAIZZEN.

Configurar el inicio de sesión automático

  1. Abre el gestor de contraseñas de este perfil Chromium.
  2. Guarda allí el usuario y contraseña de un sitio que administras o tienes autorizado.
  3. Entra a la página de inicio de sesión de ese sitio y permite que Chromium guarde la contraseña si te lo propone.
  4. Regresa al catálogo y pulsa su tarjeta; el navegador podrá sugerir o completar las credenciales guardadas cuando aparezcan los campos.

Si no se abre, escribe en la barra de direcciones chrome://password-manager/passwords o chrome://settings/passwords.

Diagnóstico rápido

Si se abre la URL pero no aparecen las credenciales, comprueba que las guardaste en este mismo perfil, que el dominio del formulario coincide con el sitio guardado y que el sitio permite autocompletar. Los tres perfiles de KAIZEN usan carpetas de usuario independientes.

Si el catálogo marca «Requiere acceso», solo se abre la URL pública. Esta opción no importa cookies, contraseñas ni sesiones que el servidor haya restringido. El gestor de contraseñas utiliza únicamente los accesos que hayas guardado tú.

Algunos sitios requieren CAPTCHA, 2FA o seleccionar la cuenta manualmente. Ninguna de estas medidas se evita automáticamente.
